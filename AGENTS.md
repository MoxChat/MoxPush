# MoxPush Release Repository Rules

1. This repository contains MoxPush release artifacts and deployment documentation only.
2. MoxPush source, product specifications, and notification protocol design are maintained in the main Mox source repository.
3. Never add APNs `.p8` keys, real provider credentials, device tokens, database files, local caches, or source code.
4. Binary and LPK files must be generated by the main repository release workflow and match the documented version.
5. Deployment documents must not redefine relay grants, push authorization, or deduplication behavior.
